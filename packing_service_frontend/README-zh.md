# 前端项目说明文档

## 1. 项目简介

本项目是基于Vue-admin-template框架开发的前端单页面应用（SPA）。本框架旨在提供【一句话描述项目核心功能或目标，例如：高效的数据可视化展示与交互操作】。目前版本为 `v4.0+` 基于 `vue-cli` 进行构建。

## 2. 环境依赖

在运行或构建本项目之前，请确保本地环境已安装以下基础依赖：

- **Node.js**: 建议版本 `v18.19.0` 或以上 （请务必保证 Node 版本兼容）
- **包管理工具**: 推荐使用 `npm` (Node 自带) 

## 3. 安装与运行

请在终端（命令行）中进入项目根目录，按顺序执行以下指令：

### 3.1 安装项目依赖

Bash

```
npm install
```

### 3.2 启动本地开发服务

Bash

```
npm run dev
```

*启动成功后，终端会输出本地访问地址（例如：`http://localhost:9572`），在浏览器中打开即可查看。*

- 4. 环境变量与配置说明（重点）

  本项目针对不同运行环境区分了配置文件，通常存放在项目根目录下：

  - **开发环境配置 (`.env.development`)**: 供本地开发联调使用。
  - **生产环境配置 (`.env.production`)**: 供正式上线部署使用。

  **** 如果需要更改正式环境的后端 API 接口域名，**请在执行打包命令前**，打开项目根目录下的 `.env.production` 文件，找到类似 `VUE_APP_BASE_API`（或 `VITE_APP_BASE_API`） 的变量，将其修改为贵方实际的正式接口地址。

  ## 5. 生产环境打包与部署

  ### 5.1 执行构建命令（生产环境）

  确认环境配置无误后，执行以下专门针对生产环境的打包指令：

  Bash

  ```
  npm run build:prod
  ```

  *说明：此命令会自动读取 `.env.production` 中的环境变量，对项目代码进行压缩和混淆，生成最适合线上运行的纯静态文件。*

  ### 5.2 部署说明

  - 构建完成后，项目根目录下会自动生成一个名为 `dist` 的文件夹。
  - 只需要将 `dist` 文件夹内部的所有文件，上传至您的 Web 服务器（如 Nginx、Apache、Tomcat 等）的指定站点根目录下即可完成前端部署。

  ## 6. 核心目录结构说明

  为了方便贵方后续的二次开发或运维，以下为核心目录结构：

  - `src/` : 项目源代码主目录
    - `assets/` : 静态资源（图片、全局样式等）
    - `components/` : 全局公共组件
    - `views/` : 页面级视图组件
    - `router/` : 路由配置文件
    - `store/` : 全局状态管理
    - `utils/` : 工具函数库
    - `api/` : 接口请求封装
